Quick start

  1. Capture: search for the woman by Unique ID, name or phone. If she is not found, register her, enroll the pregnancy (LMP), then open ANC 1.
  2. Data upload: upload registers or reports as Excel/CSV (rows are stored in the database and can be imported as events with the template), or Word/PDF (file kept in Drive, text captured for search).
  3. Data browser: view and download any table you have access to.

Spreadsheets and documents uploaded for your facilities. Open one to read its rows; rows that carry a Unique ID link to the client's record.

Data upload

To import rows as tracker events, use a template: columns umid, event_date (YYYY-MM-DD) and data element codes. Rows whose UMID has no active pregnancy in your facilities are skipped.

KoBo / ODK data collection

Collect on phones with KoBoCollect, ODK Collect or KoBo web forms (Enketo), offline if needed. Each visit form finds the client by facility + age + date of first ANC, card scan, Unique ID or name, and fills in her Unique ID, facility, EDD and risk flags from the client list.

1. Download the forms (XLSForm)

Field names are the platform's data element codes, so submissions map straight into the tracker.

2. Download the client list (clients.csv)

Attach it to every visit form as a media file named clients.csv (KoBo: form → Settings → Media; ODK Central: form → Attachments). Download a fresh copy whenever new women are registered.

It contains names, ages and phone numbers for your facilities. Keep it on project devices only.

3. Send submissions to the platform

KoBoToolbox: project → Settings → REST Services → Register a new service. Paste this endpoint URL and choose JSON. Each submission is then saved automatically, and appears in the Submissions table of the Data browser.

ODK Central or a KoBo export: download the submissions as CSV/XLSX with field names as headers and use Data upload → Import as … events. Group prefixes such as g2/ are removed automatically.

Data received from KoBo / ODK

Every submission received, with its values. Saved visits also appear in the client's record in Capture (Source: Upload / KoBo).

Pull submissions from KoBoToolbox

Use this if you prefer not to set up a REST Service, or to fetch anything missed. Find the API token under KoBo → Account settings → Security, and each form's asset UID in its URL (…/forms/aXyZ…/).

How forms find the client

  1. Registration form creates a new woman, or updates her if facility, age, first ANC date and surname match an existing client. The platform generates her Unique ID when the submission arrives.
  2. Visit forms (ANC 1, ANC follow-up, delivery, PNC, loss, referral, exit) start with "Find client": by age + date of first ANC at your facility, card scan, Unique ID or name. The form then shows her Unique ID, facility, age, first ANC date, village, ANC number, EDD and risk flags, and asks you to confirm before you continue.
  3. ANC 1 asks for the LMP when she has no active pregnancy. The platform then opens a new pregnancy record automatically.
